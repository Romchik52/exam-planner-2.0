About The Project

Project Name

Exam Preparation Planner

Project Goal

This web application helps students organize and track their exam preparation tasks efficiently.

Technologies Used

  • HTML5
  • CSS3 (Flexbox & Grid)
  • JavaScript (ES6+)
  • LocalStorage
  • Chart.js

How To Use

Add tasks on the Add Task page, use filters and search on the home page, and review your progress on the Statistics page.
